# OSC Fire Control (Android)

Native Jetpack Compose port of https://github.com/cubicmetre/osc-fire-control

## Build the APK
**With GitHub (no PC needed):** push this project to a GitHub repo, open the *Actions* tab,
run **Build APK**, then download `osc-fire-control-apk` from the finished run.

**With Android Studio:** open the folder, let it sync, then Build > Build APK(s).
(The debug build uses Android's default debug key; no keystore file is required.)
